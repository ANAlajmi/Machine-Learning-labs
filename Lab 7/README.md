This project involves building a logistic regression model to predict whether a user will click on an advertisement based on demographic and behavioral data. Using Python libraries such as pandas, seaborn, and matplotlib, the initial phase focused on exploratory data analysis. This included visualizing age distributions and identifying key correlations, such as income versus age and site time versus daily internet usage, to understand underlying user patterns.
Following the data exploration, relevant numerical features, including Daily Time Spent on Site, Age, Area Income, Daily Internet Usage, and Gender, were selected to train the model. The dataset was split into training and testing sets (67% and 33%) to ensure an unbiased evaluation. A Logistic Regression model was then successfully trained and evaluated against the unseen data, ultimately achieving a 91% overall accuracy and demonstrating strong predictive performance across precision and recall metrics.
