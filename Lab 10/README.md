In this assignment, I applied Support Vector Machine (SVM) classification to the classic Iris flower dataset to practice building, evaluating, and tuning a machine learning model.
I started by loading the Iris dataset using Seaborn and performing exploratory data analysis. I generated a pairplot of all feature combinations colored by species, which revealed that Iris setosa is the most linearly separable species; it clusters cleanly away from versicolor and virginica, especially along petal length and petal width. I also created a KDE (Kernel Density Estimation) plot of sepal length versus sepal width, specifically for the setosa class, to visualize the density of its feature distribution.
Next, I split the dataset into training and testing sets using a 70/30 split, then trained a Support Vector Classifier (SVC) from scikit-learn on the training data. After generating predictions on the test set, I evaluated the model using a confusion matrix and a full classification report. The baseline model performed extremely well, achieving 98% accuracy with near-perfect precision and recall across all three species.
To practice hyperparameter tuning, I then used GridSearchCV to systematically search over a grid of C and gamma values for the RBF kernel. After fitting the grid search to the training data and generating new predictions, I compared the resulting confusion matrix and classification report against the baseline. The tuned model produced identical results, which is expected given that the Iris dataset is small and well-structured, meaning the default SVC parameters were already close to optimal.
Overall, this assignment reinforced my understanding of the SVM workflow: data exploration, model training, performance evaluation, and hyperparameter optimization with GridSearchCV.
