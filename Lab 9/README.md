This project explores historical lending data from LendingClub.com to build a machine learning classification model that predicts whether a borrower will pay back their loan in full. The analysis began with exploring borrower profiles and financial metrics, observing how factors like FICO scores and loan purposes correlate with repayment status and interest rates. After visualizing the trends, the data was preprocessed by converting categorical features into numerical formats using dummy variables, creating a clean dataset ready for machine learning algorithms.

For the predictive modeling phase, the data was split to train and evaluate both a standard Decision Tree and a Random Forest Classifier. Although the Random Forest model achieved a much better overall accuracy (85%) compared to the single Decision Tree (72%), further evaluation of the confusion matrices and classification reports revealed a major challenge: class imbalance. Because most loans in the dataset were paid off, the models struggled to accurately identify the minority of borrowers who defaulted, highlighting the need for future improvements like advanced feature engineering or dataset balancing techniques to handle heavily imbalanced real-world data.
